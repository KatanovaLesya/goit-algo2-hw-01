### Завдання 1: Пошук мінімального та максимального елемента

Реалізовано функцію `find_min_max(arr)`, яка:

- Приймає масив чисел довільної довжини.
- Використовує рекурсивний підхід «розділяй і володарюй».
- Повертає кортеж `(мінімум, максимум)`.
- Працює зі складністю **O(n)**.

### Приклад

````paython
arr = [3, 1, 5, 2, 8, 4]
print(find_min_max(arr)) 
````

### Завдання 2: Пошук k-го найменшого елемента

Реалізовано функцію `quick_select(arr, k)`, яка:

Шукає k-й найменший елемент у несортованому масиві.
Побудована на принципі QuickSelect (розділяй і володарюй).
Не сортує масив повністю.
Середня складність — **O(n)**.

### Приклад 2

````paython
arr = [7, 10, 4, 3, 20, 15]
print(quick_select(arr, 3))  
````
